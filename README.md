# 🦫 Beaver Genomics Susceptibility Model

This project utilizes a *Random Forest Machine Learning model* to predict genomic susceptibility within the Castor canadensis (North American Beaver) population.

## 📊 Performance Metrics
*   *Model Accuracy:* 94%
*   *Focus:* Protein conservation and genomic variations.

## 📁 Repository Contents
*   genomics_analysis.py: The core Python script containing the ML pipeline and data processing.
*   Beaver_Genomics_Importance.png: A visualization highlighting the most significant genomic features identified by the model.

## 🚀 Usage
To run the analysis:
1. Ensure you have scikit-learn, pandas, and matplotlib installed.
2. Run the script: python genomics_analysis.py
